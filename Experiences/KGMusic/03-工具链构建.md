# 酷狗 KGG 解密工具构建

> 工具：`tools/KgDec.py`（纯 Python，最终采用）

## 为什么用纯 Python 而不是原生 C / P/Invoke

| 方案 | 结果 |
|------|------|
| 直接调 `QMDECRYPTION.dll` | ❌ key 语义是腾讯 EncV2 体系，酷狗派生 key 不兼容，Decrypt 乱码 |
| proxy DLL hook 观察真实 key | ❌ 酷狗是 CEF 宿主，无界面环境启动即退出(0)，无法触发 |
| 纯 Python 实现算法 | ✅ 完整可用，40MB FLAC 约 8s，OGG 数秒 |

## 依赖

```bash
pip install cryptography
```

## 用法

```bash
# 单文件
python tools/KgDec.py "path\to\song.kgg" "output_dir"

# 目录批量（自动遍历 *.kgg）
python tools/KgDec.py "musics\KGMusic" "output"

# 手动指定数据库
python tools/KgDec.py file.kgg out --db "C:\...\KGMusicV3.db"
```

工具自动：
1. 定位数据库：`%APPDATA%\KuGou8\KGMusicV3.db`（找不到时可 `--db` 指定）
2. 解密数据库（AES-128-CBC 分页）
3. 解析 KGG 头部拿 `audio_hash`（偏移 0x48）
4. 查 `ShareFileItems` 表取 eKey
5. eKey → TEA 派生 512 字节 key → RC4/Map 解密
6. 按魔术字节输出 `.flac/.ogg/.mp3`

## 数据库解密实现（AES 分页，cryptography 库）

```python
def decrypt_database(data):
    if data.startswith(b"SQLite format 3\x00"): return data   # 明文直通
    buf = bytearray(data)
    decrypt_page1(buf)            # 第 1 页特殊：校验+置换+解密
    for pg in range(2, len(buf)//PAGE_SIZE + 1):
        off = (pg-1)*PAGE_SIZE
        buf[off:off+PAGE_SIZE] = aes_cbc_dec(buf[off:off+PAGE_SIZE],
                                             page_key(pg), page_iv(pg))
    return bytes(buf)
```
